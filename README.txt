SHAFFAF KNITS WEBSITE
=====================

SEE IT ON YOUR COMPUTER: double-click "index.html".

PAGES
  index.html          Home
  about.html          About us
  products.html       The collection
  manufacturing.html  Needle counts and sampling
  custom.html         Custom / Private Label
  contact.html        Contact and enquiry form

OTHER FILES
  styles.css, anim.css   Colors, layout and animation styles
  site.js, anim.js       Menu, product filter, enquiry form, animation
  img/                   Your logo, sock photos and certificate logos

CHANGE TEXT: open a page in Notepad, change the words (not anything inside
< > brackets), save, and refresh the browser.

CHANGE A PHOTO: put a new photo in the img folder with the same file name.

PUT IT ONLINE: upload the whole folder to a hosting service
(for example Netlify Drop, GitHub Pages, or your web hosting company).
